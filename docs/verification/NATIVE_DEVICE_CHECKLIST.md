## M2 플랜

- 320dp 폭과 글자 배율 1.0/1.5/2.0에서 잘림·가로 스크롤이 없다.
- 라이트/다크에서 본문·버튼·포커스가 읽힌다.
- TalkBack/VoiceOver로 4탭을 한 번씩만 순회하고 선택 상태를 읽는다.
- 한국어 IME 조합 중 검색이 깨지지 않고, 직접 입력/가격 폼이 키보드에 가리지 않는다.
- 빠른 연속 탭에도 같은 곡/셋리스트가 중복 추가되지 않는다.
- 재정렬, 삭제, 되돌리기와 계산 적용 후 앱을 강제 종료·재실행해도 같은 revision이 남는다.

## M3 티켓·PNG

- 현재 revision 발권 모션은 한 번만 나오며 모션 축소에서는 즉시 표시된다.
- 앞/뒤 전환과 긴 100곡 뒷면 스크롤을 보조기술로 조작할 수 있다.
- 갤러리 추가 권한 거부/허용/재시도 문구가 정확하다.
- 저장 PNG가 정확히 1080×1350이고 잘림 없이 곡수·약 시간·총액·1인당·TEST DATA를 표시한다.
- PWA 기준 이미지와 나란히 하프톤·그레인·타공·서체 fallback을 product owner가 승인한다.
- Android/iOS 공유 시트에서 PNG가 열리고 수신 앱에서 읽힌다.

## M4/M5 링크 handoff

- 폰 A에서 링크 생성 후 복사·OS 공유·철회가 동작한다.
- 카카오톡에 붙여 넣은 HTTPS 링크가 절대 OG 제목/설명/이미지를 표시한다.
- 폰 B 앱 미설치 상태는 읽기 전용 랜딩, 설치 상태 cold start는 `/import` 미리보기로 간다.
- 미리보기만으로 현재 플랜은 바뀌지 않는다.
- 비어 있지 않은 플랜은 교체 확인 뒤 가져오며 즉시 되돌릴 수 있다.
- 같은 slug 두 번째 가져오기는 중복으로 저장하지 않는다.
- 폐기/만료/오타 slug는 API와 랜딩 모두 generic unavailable이고 OG 이미지를 남기지 않는다.

## 설정·업데이트·삭제

- 프로필 사진이 512×512 JPEG로 앱 document 영역에 남고 공유 payload/PNG에는 포함되지 않는다.
- 앱 업데이트 없음/있음/실패 상태 문구와 production channel을 확인한다.
- 전체 데이터 삭제 뒤 플랜·티켓·링크 capability·프로필 사진이 사라지고 새 플랜 편집이 가능하다.
